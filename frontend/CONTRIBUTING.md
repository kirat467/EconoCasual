# Working on this repo (team rules)

- Work on your own branch (`member-name`), never directly on `main`. The Team Lead merges.
- Commit small, meaningful changes with clear messages, e.g. `add CSV delimiter detection`, `fix trend chart resize`.
- Do not make empty, one-character or duplicate commits. They do not count.
- Update the README when you add a feature or change how to run the project.
- Check before pushing: open `index.html`, test group buttons, CSV upload, dark mode, and a phone-width window.
